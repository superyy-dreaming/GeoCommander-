# 首页、地图与设置设计依据

原生 Godot 桌面战术游戏，Operate / Read。继承 DESIGN.md 的深底网格、青蓝操作、金色协同、系统中文字体和程序化几何；世界 HDR 与 CanvasLayer 10 的文字分层。

首页左侧单人游戏、多人游戏、设置，下方独立兵种演练；右侧用真实地图定义绘制战区。单人页左选图右预览，固定底部返回和进入准备。多人页明确开发中，创建与加入禁用。演练复用五兵种真实攻击技能，退出即清理上下文。

六图为均衡前线、双翼迂回、折光阵列、盘旋堡垒、交叉火线、晶脉迷城，统一经济与胜负并使用3200×1800空间。设置为显示、界面、LLM、操作与关于页签，普通修改即时保存，显示修改15秒确认回退；战中打开暂停全部推进，关闭恢复原暂停态及焦点。全屏捕获进入前最后稳定的实际窗口布局，并等比放大整个画面；游戏内切换和macOS原生全屏入口行为一致，宽高比不同时居中留边。字号100/115/130/150/180%，在逻辑画布内独立调整界面文字，不改变世界单位的逻辑尺寸。

首屏承诺：三个主动作和独立演练一眼可见，地图预览与真实生成一致。最低1280×720，大字号下所有关键控件可达，演练画布等比缩放，档案与设置正文独立滚动。键盘焦点清晰，中文输入与模态界面阻断战场输入。

视觉证据：artifacts/launcher-visual-report.json 列出40个真实Metal截图及尺寸，覆盖1280×720、1440×900、1920×1080和Retina 2×，含首页、三地图、设置及显示确认、多人、五演练档案、矩阵、战场与结算。经过批量修复及独立审查的定向确认，报告可见控件越界为空。artifacts/launcher-contact.png 仅为这些真实截图的缩略总览，单张PNG为原始HDR帧缓冲按sRGB编码。

系统字体使用稳定生命周期的共享Theme；macOS字体集合可能将PingFang SC解析为HK字面，因此显式加入系统Hiragino Sans GB回退，不打包字体、不以改写文案规避缺字。原生流程检查关键简体字形，并检查字号、显示回退与暂停。
