# 精细战术编排 v2

## 使用

启动 `./run.command`，进入“兵种演练 → 提示词 → 布阵验证”。五个兵种分别保存提示词、有效方案和未完成的 JSON 草稿。

1. 在设置的 LLM 页填写 Base URL、当次运行的 Key 和模型，测试连接。
2. 描述动作顺序、结束条件、等待上限、失败后做什么，点击“AI 生成 JSON”。
3. 在“步骤”页检查方案；“步骤操作…”提供添加、删除、排序、撤销、重做和本兵种示例。修改表单后点击“应用步骤修改”。条件、技能参数和中断数组使用表单中的 JSON 区域编辑。
4. 选择地图。地图工具中“布阵”操作双方单位，“编辑路径”左键增加或拖动航点、右键删除，“选择掩体”点击墙体。滚轮缩放、中键平移。布阵参数位于“布阵”菜单的属性面板。
5. 点击“应用并重跑”。每次恢复相同初始阵容、生命和种子，使用正式冷却与真实碰撞。“暂停”后可前进一个物理帧；选中 v2 单位后，“到下一步”运行到下一次步骤切换，最长运行 3600 帧后暂停。
6. 检查“规则读数”和“事件”。确认后点击“应用开局”，仅替换当前兵种；正式对局的新部署单位各自从入口开始。

无效 JSON 原文会保留，不能应用。AI 请求失败、取消、过期或校验失败时，旧有效配置保留，不改用关键词。切换兵种、地图、离开页面或修改连接配置会取消相关请求。

## 推荐提示词

> 向上移动2秒；寻找能遮挡目标菱形直射的可达墙体后方；等待冲刺就绪，最多5秒；移动到菱形背后；满足实际背刺条件后冲刺；完成后返回掩体并循环。生命低于30%时中断并撤退。

可额外明确：“未指定的步骤禁止普攻与自动技能；没有可达掩体或目标丢失就停止并报告；撤退完成后恢复被中断步骤。”

需要赶路冲刺时明确写出允许的阶段。方向移动只保持进入步骤时的地图方向，遇墙受阻；“移动到某处”或航点路径会寻路。不要用“向敌方基地”代替背刺瞄准，敌人的真实朝向可能变化。

## JSON 合同

根对象为 `{version:2, unit_type, base, plan}`。`base` 兼容 v1 原有字段，并可选`terrain_strategy`；v2 运行时以步骤控制行动，只在显式 `finish:base` 后转用基础战术。

`plan` 包含 `entry`、`steps`、`interrupts`、`finish` 和 `map_id`。每种最多24步、8条中断，合计128个条件节点，条件深度最多4。提示词最多4096字符。

| 步骤字段 | 含义 |
|---|---|
| `id` / `label` | 唯一标识 / 可选说明 |
| `action` | 下表中的动作 |
| `target` | `current`、`nearest`、`diamond`、`hexagon`、`lowest_hp`、`base`、`none`。进入步骤时选择并锁定；后续可跟踪同一目标的位置 |
| `attack` | 是否允许原地普攻，默认关闭；不会因此追敌 |
| `skill` | `hold`保留、`auto`允许现有自动技能、`travel`允许三角赶路冲刺，默认保留 |
| `seconds` | 方向移动或无条件等待的持续秒数 |
| `when` | 显式完成条件；可用于条件分支 |
| `timeout` | 步骤最长等待，默认20秒。条件等待必须使用这个字段，不能同时填写`seconds` |
| `next` / `on_failure` | 成功 / 失败跳转。默认成功`end`、失败`stop`；也可填步骤id；中断处理可用`return` |

| `action` | 作用 |
|---|---|
| `move_direction` | 固定八方向、前后或角度，持续`seconds` |
| `move_to` | 到`goal`，自动绕开地图地形 |
| `follow_path` | 按`path:[[x,y],…]`顺序推进，每个航点之间寻路 |
| `seek_cover` | 寻找能遮挡所选威胁直射的可达墙体，可用地图中的稳定`obstacle` ID限定 |
| `peek` | 从上一次掩体寻找可达且能直视威胁的探出位置 |
| `flank_target` | 按目标实际朝向到其背后，检查安全位置 |
| `wait` | 等时长或条件 |
| `attack_target` | 原地攻击，目标消灭后完成 |
| `cast_skill` | 等待就绪和合法施放，等待真实技能完成后跳转 |
| `retreat` | 寻路返回己方基地附近 |

方向`up/down/left/right`对应地图，`forward/backward`对应基地进攻方向，`angle`的0度向右、90度向下。目标或基地的到达距离包含真实碰撞半径。

`goal.anchor`支持`point`、`target`、`rear`、`target_left`、`target_right`、`home`、`enemy_base`、`cover`、`north_prism`、`south_prism`；`point`需要`point:[x,y]`，目标侧后方可选`distance:30..600`。

`finish`默认为`hold`原地待命，可显式选择`base`或`repeat`。每物理帧最多一次步骤跳转，循环不会同步卡住主线程。

## 条件与中断

条件为`{fact,op,value}`，或非空`all`、`any`、`not`组合。比较支持`eq/ne/lt/lte/gt/gte`；布尔与类型只支持`eq/ne`。

保留 v1 的生命、距离、目标类型、附近数量、友军最低生命、六边形存活、技能就绪、目标可见和目标聚集数量。新增：

- `match_time`：对局时钟；`unit_time`：该单位进入执行器后的物理时间。
- `step_time`：当前步骤已运行时间。
- `arrived`、`target_lost`、`in_cover`、`cover_valid`。
- `action_done`、`action_failed`：动作本身的结果，可参与完成条件。
- `step_attacks`、`step_skills`、`step_visits`：当前步骤普攻、技能启动和访问次数。

每条中断为`{id,when,goto}`，按数组顺序匹配，不能嵌套。处理期间保存原步骤时间、路径游标和掩体；`return`恢复剩余进度。触发条件解除后才能再次触发。主流程不能`return`。暂停与受控冻结步骤时间，中断只冻结被挂起步骤；已启动的技能先正常结束，现有 EMP 控制可打断施法。

无路径、无掩体、目标失效、超时和技能中断均有文字原因。技能尚未就绪或位置不合法时继续等待到上限；未配置失败分支就停止该单位方案。

## 技能参数

`skill_request`采用`{aim,purpose,…}`，瞄准支持`auto/target/direction/point/self`，用途支持`attack/travel/backstab/support/reflect`，按兵种校验。

| 兵种 | 控制与限制 |
|---|---|
| 三角 | 定向、定点或瞄准目标；赶路需要安全净空，背刺同时检查真实背后角度、可达距离与冲刺轨迹。推荐`{aim:target,purpose:backstab}` |
| 方形 | 定盾朝向；`support`保护，`reflect`可自动求协同朝向。明确指定方向时保留该方向 |
| 圆形 | 指定目标或地面中心；320px内、160px聚集范围至少2个敌军，`cluster_3plus`仍需3个 |
| 菱形 | 目标、方向或点；保持650px施放判断、0.5秒蓄力、750px总路径、最多两次真实反射和命中去重 |
| 六边形 | 自身脉冲，`auto/self`；无直接普攻，无远程定点治疗 |

伤害、速度、冷却、反射倍率和技能结算来自原有实现。拒绝施放不扣冷却；实际启动、完成、中断、拒绝均有结果。模型输出不执行为代码，不逐帧请求模型。

墙体掩体仅遮挡来自指定威胁的直射。敌方移动可能暴露藏身点；晶簇可能反射激光，熵减区不算掩体，对范围技能没有免疫。是否重新寻找掩体由方案跳转决定。

## 地图与保存

手工航点、坐标技能或指定墙体的方案必须绑定六图之一：`balanced/flanks/refraction/spiral_fortress/crossfire/crystal_maze`，且落点通过边界和真实地形检查。纯语义方案可留空。地图不匹配时禁止应用或开战，并标明相关兵种；实验室和准备矩阵均可单独恢复该兵种默认，其他兵种保留。

实验文件升级为`user://tactic_laboratory_v2.json`。首次没有v2文件时读取旧v1文件；首次保存前建立原文件`.pre-v2`备份，保留原提示词和v1 JSON。有效配置和无效的编辑草稿分开保存。备份或保存失败会提示“本次运行已生效，未保存”，可重试。

正式开局、选图仍仅在本次程序运行保存。Key仅内存，不写实验、连接配置、日志或截图。“恢复游戏默认设置”不会删除实验和 LLM 连接。

可编辑示例位于`tests/fixtures/tactic-v2-{triangle,square,circle,diamond,hexagon}.json`；真实模型生成的三角方案为`tests/fixtures/tactic-v2-generated-triangle.json`。验证命令与证据见[tactic-plan-verification.md](tactic-plan-verification.md)。

地图空间版本3、实验格式版本4和机关语义目标的规则及迁移步骤见[地图与交互地形](map-overhaul.md)。普通激光仍遵守原有750px/两次反射，分光棱镜采用独立的三分支规则。
