# 地图与交互地形

本轮地图空间为2400×1350，空间版本3，六个地图ID保持不变。启动方式仍为`./run.command`。首页“单人游戏”选择地图后进入准备矩阵；实验室的“地图”菜单可选择相同六图。重开恢复机关初始状态。

基地位于(240,675)/(2160,675)。能源点随地图变化，导航、预览和实战从同一份地图定义读取。地图1红方楔形墙为160°/−160°；地图6红方外堡垒为205°，均按实际轮廓校验中心旋转对称。

四类墙体为倒角堡垒、V形墙、楔形胸墙和六棱立柱。V形墙保留凹口并分解物理碰撞；发光外沿不参与碰撞。四层绘制、地面三路导流线、基地和能源点图形在预览、战场、实验室复用。预览使用独立HDR SubViewport与World2D，没有单位、经济或真实机关结算。

预览“几何检查通过”仅表示ID、边界、镜像及实体相交检查通过。悬停可见真实最小实体间距，通行另由物理回放验证；不承诺所有物体间有170px净空。图例换行，说明和地图列表独立滚动。低动效关闭装饰旋转、滚动和闪烁，危险范围及文字仍显示。

## 六类机关

| 机关 | 行为与限制 |
|---|---|
| 分光棱镜 | 固定半径48px外壳，内部星形0.25rad/s旋转。一次激光最多分光一次；中束85%，左右±26°各75%，每束总路径650px，包含后续反射，继承已用的两次反射预算与已有增伤。中束只选择可感知敌军，无目标沿命中法线发射。再次撞分光体终止。同次施法对同目标只取最高命中段伤害。 |
| 加速轨 | 680×86，同向点积≥0.1时主动移动×1.75，逆向<−0.2时×0.65，其余中性。与熵减、超频、传送增益相乘，不放大拉拽与击退。 |
| 隐匿星云 | 六边形半径115px，单位透明度0.45。同一星云敌军、145px内观察者或被该队伍显形的单位可被感知，其余敌军不能锁定。扫描和EMP显形3秒，按观察队伍记录。隐匿不阻止真实激光、范围伤害或已发弹体命中。 |
| 成对虫洞 | 每单位8秒冷却，传送后2秒主动移速×1.35。每对共享5次，用尽后14秒恢复。先验证安全出口，再同时结算位置、次数和冷却；失败不扣次数。保留已启动动作，重置冲刺轨迹，跨虫洞跨度不造成穿刺伤害。 |
| 动态闸门 | 150×18，初始关闭；20秒关闭、15秒开放。关闭前沿法线用物理移动推离单位；安全空间不足时保持开放，显示受阻原因，情况变化后重试。 |
| 过载反应堆 | 每55秒循环，最后6秒预警。爆炸对范围210px内单位造成160伤害，生成三个各50 Flux晶体。生成方向每周期转60°；无安全落点的奖励保留待生成并显示原因。晶体保留至拾取或离场。24px拾取半径，同帧按距离、部署序号、队伍顺序解决竞争。 |

普通护盾+35%、晶簇+25%反射增伤保持不变。普通激光总路径750px、最多两次反射，按真实法线反射，不自动转弯追踪。

六边形新增独立扫描：自身240px，8秒冷却，显形3秒，初始可用。普通AI就绪自动扫描；精细编排必须显式施放。扫描不治疗、不消耗治疗冷却，也不增加主技能计数。暂停或EMP控制期间不能施放。

准备、暂停、结束不推进机关时钟、传送冷却、拾取或爆炸。所有状态归属各自CombatContext；离场清理减速、隐匿、显形、闸门推力与传送增益。正式拾取事件仅由MainArena修改Flux；实验室只记本地收益。

## 地形提示词与JSON

战中关键词仍是整队替换，冲突按文本顺序覆盖。可以使用“加速轨/加速带/高速包抄”“虫洞/折跃/奇袭后排”“星云/隐匿/埋伏”“分光/中央棱镜/三向激光”“躲避过载/撤出红圈/抢晶簇”。具体枚举以本地校验器为准。

普通AI默认避开反应堆预警。精细方案继续遵守显式步骤；不会因为附近有机关就擅自追敌或改向。方向步骤保持进入步骤时的方向，目的地步骤才使用绕障路由。加速轨和虫洞不能保证任何位置都更快。

v1的base/rule actions及v2步骤可选`terrain_strategy`：`auto / none / rails / portals / nebula / splitter / avoid_hazards / collect_flux`。v2未授权时不自动借用虫洞或撤离预警。

新增语义目的地`goal.anchor`：`rail_entry / rail_exit / portal / nebula / splitter_firing / safe_zone / flux_crystal`。对应机关不存在、出口不安全、无次数或路径不可达时明确失败。虫洞与拾取完成依据真实事件，接近点位不算成功。

新增布尔事实：`scan_ready / in_nebula / portal_ready / portal_available / gate_open / reactor_warning`。新增累计事件事实`portal_used / flux_collected`，步骤事件计数`step_portals / step_pickups / step_scans`。原`skill_ready / step_skills`仍只指主技能。

六边形扫描步骤片段，需放进有效v2方案的`steps`数组：

```json
{
  "id": "scan",
  "action": "cast_skill",
  "target": "none",
  "attack": false,
  "skill": "hold",
  "skill_request": {"ability": "scan", "aim": "self", "purpose": "support"},
  "timeout": 8,
  "next": "end",
  "on_failure": "stop"
}
```

可复制的提示词示例：

- 三角，在盘旋堡垒：“先使用可用虫洞，确认实际传送后再向敌方基地推进；没有可用虫洞或安全出口时停止并说明。不要把接近虫洞当作传送成功，保留技能。”
- 菱形，在折光阵列：“移动到能实际命中中央分光棱镜的发射位置，再用真实折射激光攻击。只锁定可感知敌人，不能修改射程或反射次数；无可用发射位就停止。”
- 六边形：“先在原地扫描；扫描完成后进行原有治疗。扫描和治疗各自等待真实冷却，不把扫描计入主技能次数。”
- 晶脉迷城：“正常推进。反应堆预警时通过中断撤到safe_zone；预警解除后恢复原步骤。明确允许collect_flux策略，拾取必须等真实事件；不使用虫洞。”

AI仍只生成候选JSON，经过版本、字段、能力、坐标和地图绑定校验后，用户明确点击应用才生效。模型可能生成不支持或不合法内容，错误时保留旧配置，不执行生成代码。本轮没有使用真实供应商凭据进行新增机关提示词烟测。

## 实验迁移与修复

实验文件保持`user://tactic_laboratory_v2.json`路径，内部格式升为4。空间版本1坐标不缩放，版本2(3200×1800)乘0.75，版本3不再次缩放。布阵、手工航点、定点目标、技能坐标及可解析JSON草稿同步迁移，语义目标不变。

先建立`.pre-map-v3-时间戳`备份，再通过临时文件原子保存。备份或保存失败时保留原文件，提示本次已生效但未保存，支持重试。更新版本空间文件不会被覆盖。

旧障碍物ID消失或新落点不合法时，保留原方案和原JSON，标记待修复并定位兵种/步骤，阻止对应应用或开战。处理方法：进入该兵种JSON/步骤页，重新选择地图上实际存在的墙体或安全航点，校验后应用；也可明确单独恢复该兵种默认。旧布阵不会静默替换，需手动调整，或确认载入新的标准预设。新标准阵容已验证适合六图。

正式开局方案和选图仍只在本次运行生效。Key只在内存。游戏设置恢复默认不删除实验或连接配置。

## 源码边界与回滚

- `MapCatalog`：地图坐标、轮廓、稳定ID、校验及空间迁移。
- `TerrainArt / MapDisplay / MapPreview`：共享程序化绘制及只读预览。
- `TerrainRuntime / TerrainObject / TriSplitter`：机关生命周期与局部事件。
- `TerrainGraph / ArenaObstacles`：动态拓扑、虫洞连接、路由与三射线。
- `BeamTrace`：普通和分支激光的唯一几何结果。
- `SkillRequest / BaseGeoUnit / UnitHexagon`：感知、移动倍率和独立扫描。

实验室布局、180%字号和已有全屏状态机保留。战场工具不足以横排时切为部署/终端/全局指挥三页，页内滚动，不缩小字号；正文、资源和按钮避免互相遮挡。

本机回滚快照与逐文件清单见`artifacts/map-overhaul-source-manifest.json`，使用说明见[验证记录](map-overhaul-verification.md)。不要用Git硬重置或整包覆盖工作区，否则会丢失本轮之前已有改动。
