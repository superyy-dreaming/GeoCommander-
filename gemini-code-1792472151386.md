## 1. CRITICAL AGENT GUARDRAILS (READ FIRST)

1. **Zero Missing Assets**: Never write `load("res://icon.svg")` or load external textures. Use `Polygon2D`, `Line2D`, `ColorRect`, and procedural `Curve`/`Gradient` resources created in code.
2. **Avoid `.tscn` UID Hallucinations**: Godot 4 `.tscn` files can break if UIDs or sub-resource indices are malformed. **Keep `.tscn` files minimal** (root node + script attachment only) and **construct child nodes (`CollisionShape2D`, `Polygon2D`, `Line2D`, `Timer`, `Area2D`, UI layouts) programmatically inside `_ready()` or `_init()`**. This guarantees 100% syntax safety and zero broken scene references.
3. **Strict GDScript 2.0 Typing**:
   - Explicitly type all variables, arrays (`Array[BaseGeoUnit]`), dictionaries, and function return types.
   - Use Godot 4 annotations (`@export`, `@onready`) and Tween API (`create_tween()`).
   - Use `move_and_slide()` with zero arguments (velocity is a property of `CharacterBody2D`).
4. **HDR Glow Colors**: Because `hdr_2d` is enabled, set neon colors using raw `Color(r, g, b, a)` with channel values `> 1.0` (e.g., `Color(2.4, 1.8, 0.2, 1.0)`) so `WorldEnvironment` Additive Glow blooms automatically.

### 3.2 `tactical_brain.gd` (Autoload: `TacticalBrain`)
Manages the tactical JSON rules for both teams (`TEAM_BLUE = 0`, `TEAM_RED = 1`) and provides a local Natural Language -> JSON compiler (plus an asynchronous HTTP interface stub for Ollama/Cloud LLM).

- **Data Structure (`TacticalProfile`)**:
  ```gdscript
  var team_profiles: Array[Dictionary] = [
      get_default_profile(), # Team 0 (Blue)
      get_default_profile()  # Team 1 (Red)
  ]
  ```
- **Default Profile Schema**:
  ```gdscript
  func get_default_profile() -> Dictionary:
      return {
          "stance": "balanced", # aggressive | defensive | flank | kite
          "focus_fire_pos": Vector2.ZERO,
          "unit_rules": {
              "triangle": {
                  "movement": "flank_sides",        # direct_charge | flank_sides | guard_rear
                  "priority": "ranged_or_commander",# closest | lowest_hp | ranged_or_commander
                  "skill_cond": "backstab_or_grav", # on_cooldown | backstab_or_grav
                  "retreat_hp": 0.20
              },
              "square": {
                  "movement": "frontline_screen",   # frontline_screen | protect_hexagon
                  "priority": "closest",
                  "skill_cond": "ally_threatened",  # on_cooldown | ally_threatened | reflect_laser
                  "retreat_hp": 0.0
              },
              "circle": {
                  "movement": "midline_support",
                  "priority": "cluster",
                  "skill_cond": "cluster_3plus",    # cluster_3plus | on_cooldown
                  "retreat_hp": 0.30
              },
              "diamond": {
                  "movement": "max_range_kite",     # max_range_kite | align_with_square
                  "priority": "highest_threat",     # highest_threat | lowest_hp | closest
                  "skill_cond": "refract_or_snipe", # refract_or_snipe | direct_only
                  "retreat_hp": 0.45
              },
              "hexagon": {
                  "movement": "safe_backline",
                  "priority": "none",
                  "skill_cond": "always_pulse",
                  "retreat_hp": 0.60
              }
          }
      }
  ```
- **Natural Language Compiler (`compile_prompt_to_profile(team: int, prompt_text: String)`)**:
  Parse both Chinese and English tactical keywords in `prompt_text` (case-insensitive) to mutate the dictionary immediately and emit `SignalBus.tactical_profile_updated`:
  - `"绕后" / "侧翼" / "flank"` -> `triangle.movement = "flank_sides"`
  - `"切后排" / "切菱形" / "刺杀指挥" / "snipe" / "assassin"` -> `triangle.priority = "ranged_or_commander"`
  - `"保护" / "死守" / "保六边形" / "defend" / "guard"` -> `square.movement = "protect_hexagon"`, `triangle.movement = "guard_rear"`, `stance = "defensive"`
  - `"折射" / "反射" / "棱镜配合" / "refract" / "bounce"` -> `diamond.movement = "align_with_square"`, `diamond.skill_cond = "refract_or_snipe"`, `square.skill_cond = "reflect_laser"`
  - `"全军突击" / "冲锋" / "all in" / "rush"` -> `stance = "aggressive"`, `triangle.movement = "direct_charge"`, `retreat_hp = 0.0` across all units.
  - `"拉扯" / "风筝" / "后撤" / "kite" / "retreat"` -> `stance = "kite"`, raise `retreat_hp` by `+0.2` across units.

## 5. BASE UNIT ARCHITECTURE (`base_geo_unit.gd`)

`class_name BaseGeoUnit extends CharacterBody2D`

### 5.1 Programmatic Node Construction in `_ready()`
Every unit builds its own sub-nodes in `_ready()`:
- `CollisionShape2D` with `CircleShape2D` (radius matches `unit_radius`).
- `visual_root: Node2D`:
  - `inner_fill: Polygon2D` (Displays current HP ratio via scale!).
  - `outer_border: Line2D` (`width = 3.0`, closed loop, uses HDR Rim Color).
  - `team_core_dot: Polygon2D` (Small `5px` central indicator showing pure Team Blue or Team Red color for instant team readability).
- `trail_line: Line2D` (`top_level = true`, `width = 8.0`, gradient fading to transparent, stores up to 12 recent global positions).

### 5.2 Health-to-Geometry Visual Mapping (No Floating Health Bars)
- Whenever `current_hp` changes:
  ```gdscript
  var hp_ratio: float = clampf(current_hp / max_hp, 0.0, 1.0)
  inner_fill.scale = Vector2.ONE * hp_ratio
  ```
- **Hit Flash**: On taking damage, tween `outer_border.modulate` from `Color(4.0, 4.0, 4.0, 1.0)` back to `Color.WHITE` over `0.1s`.
- **Death Shatter**: When `current_hp <= 0`, spawn `TransientVFX.spawn_shatter(global_position, rim_color, unit_radius)`, emit `SignalBus.unit_died`, and `queue_free()`.

### 5.3 Utility AI Target Scoring & Steering Physics
Run target evaluation every `0.15s` and movement steering in `_physics_process(delta)`:
1. **Target Scoring (`evaluate_best_target()`)**:
   Query enemies in group `"units_team_" + str(1 - team)`. Score each enemy:
   - Base score: `1000.0 - global_position.distance_to(enemy.global_position) * 0.4`
   - If rule `priority == "ranged_or_commander"` and `enemy.unit_type in ["diamond", "hexagon"]`: `+600.0`
   - If rule `priority == "lowest_hp"`: `+(1.0 - (enemy.current_hp / enemy.max_hp)) * 500.0`
   - If enemy is inside an active `GravityWell`: `+450.0`
2. **Steering Vector Synthesis**:
   Compute `desired_dir`:
   - **Seek / Approach**: Towards `current_target` (or enemy `CoreMatrixBase` if no units nearby).
   - **Flank Offset**: If `movement == "flank_sides"` and distance to target `> 160.0`, add a perpendicular tangent vector (`dir_to_target.orthogonal() * flank_sign`) to curve around the sides of the battlefield.
   - **Kite / Retreat**: If `hp_ratio <= rule.retreat_hp` or (`unit_type == "diamond"` and enemy distance `< 220.0`), invert seek vector away from nearest enemy.
   - **Separation (Boids Anti-Overlap)**: Loop over nearby friendly units within `unit_radius * 2.6`; accumulate push-away vector `(global_position - ally.global_position).normalized() / dist_ratio` with high weight so 50 units form fluid geometric formations without stacking.
   - Apply smooth rotation: `visual_root.rotation = lerp_angle(visual_root.rotation, velocity.angle(), 12.0 * delta)`.

  - **Trigger**: Target within `110px ~ 340px` (prioritizes targets pulled by Circle's Gravity Well or targets facing away).
  - **Execution**:
    1. Windup `0.25s` (scale `visual_root` to `Vector2(0.65, 1.35)`).
    2. Dash forward at `980 px/s` for `0.28s`. Temporarily disable unit-to-unit collision blocking so it slices *through* enemies along the line.
    3. Deal `55` damage to every enemy intersected during the dash.
    4. **Backstab Crit Check**: If `dash_dir.dot(Vector2.RIGHT.rotated(enemy.visual_root.rotation)) > 0.25` (hitting enemy from behind), deal **2x Critical Damage (`110`)** and spawn a burst of bright yellow triangle sparks!

### 6.2 ■ Square (`unit_square.gd` - Class `"square"`)

- **Skill: Prism Barrier (动态棱镜)**:
  - **Trigger**: When taking damage, or when an allied Diamond is charging a laser nearby, or when enemy enters `220px`.
  - **Execution**:
    - Spawn a `PrismBarrier` node (`StaticBody2D` on Collision Layer 3) `34px` in front of the Square, oriented perpendicular to the Square's facing direction.

    - Blocks enemy movement/dashes AND serves as a **Mirror Reflector** for Diamond lasers!

### 6.3 ● Circle (`unit_circle.gd` - Class `"circle"`)
- **Stats**: Cost `45 Flux` | HP `210` | Speed `205` | Radius `17` | Ranged Attack `220px` (fires small magenta pulse orb dealing `18` dmg) | Attack CD `1.1s` | Skill CD `8.5s`
- **Skill: Orbital Collapse (轨道坍缩)**:
  - **Trigger**: Detects `>= 2` enemies clustered within `160px` of a target point (range `320px`).
  - **Execution**:
    - Spawn `GravityWell` at target cluster centroid for `1.2s`.
    - Emit `SignalBus.gravity_collapsed(team, pos, 160.0)` so allied Triangles immediately dash into the center.
    - **Phase 1 (`0.0s ~ 0.9s` Pull)**: Every physics frame, pull all enemies within `160px` toward the center (`enemy.global_position += dir_to_center * 240.0 * delta`) and draw inward-spiraling magenta rings.
    - **Phase 2 (`1.2s` Detonation)**: Deal `42` AoE damage and apply an outward knockback impulse (`110px`) with an expanding shockwave ring.

### 6.4 ◆ Diamond (`unit_diamond.gd` - Class `"diamond"`)
- **Stats**: Cost `60 Flux` | HP `105` | Speed `145` | Radius `18` | Normal Range `400px` (fast light dart `26` dmg) | Attack CD `1.4s` | Skill CD `5.5s`
- **Skill: Refracting Beam (聚焦折射激光)**:
  - **Micro-Cooperation Logic**: Before firing, if `skill_cond == "refract_or_snipe"`, check if there is a friendly `PrismBarrier` within `380px` whose reflection angle points toward an enemy cluster or enemy base. If found, aim directly at the friendly `PrismBarrier`; otherwise aim at the highest-priority enemy.
  - **Execution**:
    1. Aim windup for `0.5s`: Draw a thin crimson/white targeting laser sight line (`width = 1.5`).
    2. Fire instantaneous high-energy beam (`max_length = 750px`, `width = 9.0`, HDR `Color(3.0, 3.0, 3.5, 1.0)` fading over `0.35s`).
    3. **Multi-Segment Raycast & Reflection Math**:
       - Perform segment raycast (`PhysicsRayQueryParameters2D` colliding with Layer 3 `PRISM_BARRIER`).
       - If the ray hits a `PrismBarrier`, record the hit point, compute reflected direction `dir = dir.bounce(hit.normal)`, multiply damage by **`1.35x` (Refraction Amplify)**, and automatically steer the reflected ray toward the nearest enemy within a `35°` cone of the reflection vector! Support up to **2 bounces**.
       - For every beam segment `[p_start, p_end]`, damage all enemy units whose distance to the line segment `Geometry2D.get_closest_point_to_segment(enemy.global_position, p_start, p_end)` is `< enemy.unit_radius + 8.0` (Base damage: `85`).
